# Contributing to Gauntlet

Gauntlet is built by and for engineers who ship learned robot policies.
Contributions that move the needle on either of the two audiences in
`PRODUCT.md` (the VLA researcher or the fleet operator) are welcome.

## Quick start

```bash
git clone https://github.com/mhussainahmad/gauntlet
cd gauntlet
uv sync                                  # core install, torch-free
uv run pytest -m "not hf and not lerobot and not monitor and not pybullet \
  and not genesis and not ros2 and not isaac and not video and not render \
  and not slow and not parquet and not pi0 and not groot and not rdt and \
  not dt and not wandb and not mlflow" -q
uv run ruff check .
uv run mypy src/gauntlet
```

`uv` is the canonical package manager (see `GAUNTLET_SPEC.md` §4 — not
re-litigated). Python ≥ 3.11.

## Repo layout

| Path | What lives here |
|------|-----------------|
| `src/gauntlet/` | Library + CLI source. Public API surface is pinned in `docs/stability.md`. |
| `src/gauntlet/env/` | Environment Protocol + four shipped backends (MuJoCo, PyBullet, Genesis, Isaac). |
| `src/gauntlet/policy/` | Policy Protocol + reference policies + VLA adapters (HF / lerobot / π0 / RDT / GR00T / DT). |
| `src/gauntlet/suite/` | Declarative YAML grid (`Suite`) + loader + linter + samplers. |
| `src/gauntlet/runner/` | Parallel rollout orchestrator + Episode schema + caching + provenance hashing. |
| `src/gauntlet/report/` | Failure-analysis schema + HTML renderer. |
| `src/gauntlet/replay/`, `bisect/`, `monitor/`, `compare/`, `diff/`, `aggregate/`, `dashboard/`, `ros2/`, `realsim/` | Phase 2 / 3 features. |
| `tests/` | pytest suite (~1700 tests). |
| `examples/` | Worked Python-API examples + suite YAMLs. |
| `docs/` | RFCs, exploration notes, API reference. |
| `scripts/` | One-off dev scripts (perf benches, reference benchmark). |

## Hard rules (from `GAUNTLET_SPEC.md` §6)

- **Type everything.** `mypy --strict` must pass. No `Any` except at
  documented FFI seams.
- **Reproducibility is non-negotiable.** Every rollout reproducible from
  `(suite_name, axis_config, seed)`. If you can't reproduce a failure,
  the PR is broken.
- **Never aggregate away failures.** Reports show breakdown before mean.
- **Minimal policy adapter.** A new policy wrapper must be ≤ 20 lines.
- **No wall-of-numbers reports.** A human looks at the HTML for 10s and
  knows what to fix.
- **Small deps.** Every new dependency must justify itself. No `torch`
  in the core (policy wrappers can import it, `gauntlet.core` cannot).

## Pull-request checklist

Before opening a PR:

- [ ] `uv run ruff check .` — clean.
- [ ] `uv run mypy src/gauntlet` — clean.
- [ ] `uv run pytest -m "<your area>"` — clean. The full
      torch-free invocation lives in CI.
- [ ] **Public-API changes** (anything covered by `docs/stability.md`)
      include a `CHANGELOG.md` entry under `## [Unreleased]` and follow
      the deprecation policy.
- [ ] **Schema changes** (Episode / Report / Suite YAML / DriftReport /
      fleet_report) are additive, or include a deprecation note.
- [ ] **New entry points** (policies / envs / axes / samplers / sinks
      / cli) are registered in `pyproject.toml` and documented in
      `docs/extension-points.md`.
- [ ] No commits to root (`out/`, `*.npz`, `*.pt`, `*.results.json` —
      see `.gitignore`).

## Testing patterns

- **Unit tests** alongside the module they cover, named
  `tests/test_<module>.py`. New modules get their own test file.
- **Property / fuzz tests** under `tests/test_property_*.py` and
  `tests/test_fuzz_*.py`, marked `@pytest.mark.hypothesis_property`.
- **Determinism tests** — when asserting Episode byte-identity across
  two Runner runs (cache vs no-cache, serial vs parallel, replay
  bit-id), use `gauntlet.runner.episode_deterministic_dump` so
  wall-clock-derived fields don't surface as false diffs.
- **Backend-gated tests** carry a `pytestmark = pytest.mark.<backend>`
  so they only run when the corresponding extra is installed. CI
  runs each backend in a separate job.

## Documentation patterns

- **RFCs** for phase-major design decisions:
  `docs/phaseN-rfc-NNN-<slug>.md`.
- **Polish notes** for smaller cross-cutting changes:
  `docs/polish-exploration-<slug>.md`.
- **API reference** (`docs/api.md`) is autogenerated from public
  docstrings. New public symbols need a docstring.
- **README** is the entry point. New features that change the
  quickstart need a README update in the same PR.

## Commit / PR style

- Imperative subject line (≤ 70 chars). "Add X", "Fix Y", "Document Z".
- Reference RFC / backlog ID in the subject where applicable
  (`B-NN`, `RFC-NNN`).
- Body explains *why*, not *what* (the diff says what).
- One logical change per PR. If your PR has two unrelated subjects,
  split it.
- Squash-merge into `main`. Linear history.
